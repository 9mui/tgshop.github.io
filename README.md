# 🛍️ Telegram Mini App — Магазин одежды

Каркас интернет-магазина одежды, работающий внутри Telegram через Web App SDK.
Чистый HTML / CSS / JS без сборщиков и фреймворков — открыл, отредактировал, залил на хостинг.

---

## 📁 Структура проекта

​
clothing-shop/
├── index.html      # Разметка страницы (шапка, каталог, корзина)
├── styles.css      # Все стили и цвета
├── app.js          # Логика: рендер, корзина, связь с Telegram
├── products.js     #  Данные товаров — здесь ты редактируешь ассортимент

### За что отвечает каждый файл

| Файл | Зона ответственности | Как часто будешь трогать |
|------|----------------------|--------------------------|
| `products.js` | Список товаров, цены, категории, картинки | **Постоянно** |
| `styles.css` | Внешний вид: цвета, отступы, сетка | Иногда |
| `index.html` | Структура экрана, тексты заголовков | Редко |
| `app.js` | Логика работы приложения | Редко |

> 💡 В 90% случаев тебе нужен только **`products.js`**.

## ⭐ Как добавить новый товар

Открой файл **`products.js`**. Внутри есть массив `PRODUCTS` — это список всех товаров.
Каждый товар — это объект `{ ... }` в фигурных скобках.

### Шаг 1. Скопируй блок товара

​
{
id: 4,                          // уникальный номер (не должен повторяться!)
title: "Куртка демисезонная",   // название
price: 7990,                    // цена (только число, без ₽)
category: "Верхняя одежда",     // категория
image: "images/jacket.jpg",     // путь к картинке
},

### Шаг 2. Вставь его в массив

​
const PRODUCTS = [
{ id: 1, title: "Базовая футболка", price: 1490, category: "Футболки", image: "images/tshirt.jpg" },
{ id: 2, title: "Джинсы прямые",    price: 3990, category: "Брюки",    image: "images/jeans.jpg" },
//  твой новый товар
{ id: 4, title: "Куртка демисезонная", price: 7990, category: "Верхняя одежда", image: "images/jacket.jpg" },
];

### Правила, которые важно соблюдать

- ✅ **`id` всегда уникальный** — иначе корзина будет путать товары.
- ✅ **`price` — только число** (`3990`), без пробелов, букв и знака ₽.
- ✅ После каждого объекта ставь **запятую** `,`.
- ✅ Текст бери в кавычки: `"Название"`.

### Описание полей товара

| Поле | Тип | Пример | Описание |
|------|-----|--------|----------|
| `id` | число | `4` | Уникальный идентификатор товара |
| `title` | строка | `"Куртка"` | Название, видно на карточке |
| `price` | число | `7990` | Цена в рублях |
| `category` | строка | `"Верхняя одежда"` | Категория (фильтр сверху) |
| `image` | строка | `"images/jacket.jpg"` | Путь или ссылка на фото |

## 🗂️ Как работают категории

Категории создаются **автоматически** из товаров — отдельно их прописывать не нужно.

​
const CATEGORIES = ["Все", ...new Set(PRODUCTS.map((p) => p.category))];

То есть если ты добавишь товар с `category: "Аксессуары"`, в фильтре сверху
сама появится новая кнопка **«Аксессуары»**. Чтобы убрать категорию — просто
убери все товары с этим значением.

## 🖼️ Как добавлять изображения

Есть два способа. Выбирай любой.

### Способ 1. Картинки лежат в проекте (рекомендуется)

1. Создай папку `images/` рядом с остальными файлами:
​
clothing-shop/
├── images/
│   ├── tshirt.jpg
│   ├── jeans.jpg
│   └── jacket.jpg
2. В товаре укажи путь к файлу:
​
image: "images/jacket.jpg",

**Советы по картинкам:**
- Формат: `.jpg` или `.webp` (легче весят), для прозрачного фона — `.png`.
- Соотношение сторон: **3:4** (вертикальные), например `600×800 px`.
- Размер файла: до ~200 КБ, чтобы магазин грузился быстро.
- Имя файла — латиницей, без пробелов: `jacket-blue.jpg`, а не `Куртка синяя.jpg`.

### Способ 2. Картинка по ссылке из интернета

Просто вставь полный URL:

​
image: "https://example.com/photos/jacket.jpg",

> ⚠️ Ссылка должна быть прямой на файл (заканчиваться на `.jpg`/`.png`)
> и работать по **https**, иначе Telegram её не покажет.

## 🎨 Как поменять цвета

Открой **`styles.css`**, в самом верху блок `:root`:

​
:root {
--accent: var(--tg-theme-button-color, #2481cc);  / цвет кнопок /
--bg:     var(--tg-theme-bg-color, #ffffff);       / фон /
--text:   var(--tg-theme-text-color, #1a1a1a);     / текст /
}

Цвета по умолчанию подстраиваются под тему Telegram пользователя.
Чтобы задать свой цвет жёстко — поменяй запасное значение, например:

​
--accent: var(--tg-theme-button-color, #e63946);  / красные кнопки /

## 🚀 Как запустить

1. **Залей файлы на HTTPS-хостинг** (обязательно https):
   - [GitHub Pages](https://pages.github.com) — бесплатно
   - [Vercel](https://vercel.com) / [Netlify](https://netlify.com) — бесплатно
2. Скопируй полученный адрес сайта (например `https://my-shop.vercel.app`).
3. Открой [@BotFather](https://t.me/BotFather) в Telegram:
   - `/newbot` — создай бота (если ещё нет);
   - `/newapp` — создай mini app, выбери бота и вставь адрес сайта.
4. Открой бота → нажми кнопку — магазин запустится внутри Telegram.

## 🛒 Как обрабатываются заказы

Когда пользователь нажимает **«Оформить заказ»**, функция `checkout()` в `app.js`
отправляет данные боту:

​
tg.sendData(JSON.stringify(order));

Бот получает событие `web_app_data` с содержимым корзины:

​
{
"items": [{ "id": 1, "title": "Футболка", "price": 1490, "qty": 2 }],
"total": 2980
}

Дальше уже на стороне бота (Python / Node.js и т.д.) ты ловишь это сообщение
и обрабатываешь заказ — отправляешь менеджеру, сохраняешь в базу и т.п.
