# Telegram Mini App — Магазин одежды

Статический магазин одежды для Telegram Mini Apps. Проект работает на GitHub Pages без сборщика и фреймворков.

## Возможности

- адаптация к светлой и тёмной теме Telegram;
- мобильный каталог с фильтрами по категориям;
- изменение количества прямо в карточке товара;
- отдельный экран корзины;
- нативные `MainButton`, `BackButton` и `HapticFeedback` внутри Telegram;
- веб-резервные кнопки при открытии через обычный браузер;
- сохранение корзины в `localStorage`;
- учёт Telegram safe area;
- локальные оптимизированные WebP-фотографии.

## Структура

```text
├── index.html
├── styles.css
├── app.js
├── products.js
└── images/
```

Ассортимент редактируется в `products.js`. Изображения рекомендуется хранить в `images/` в формате WebP с соотношением сторон 3:4.

```js
{
  id: 4,
  title: "Куртка демисезонная",
  price: 7990,
  category: "Верхняя одежда",
  image: "images/jacket.webp",
}
```

`id` должен быть уникальным, а `price` — числом без знака валюты.

## Оформление заказа

При подтверждении Mini App отправляет боту только идентификаторы товаров и количество:

```json
{
  "version": 2,
  "items": [
    { "id": 1, "qty": 2 }
  ]
}
```

Цены и итог необходимо повторно вычислять на сервере. Не доверяйте цене, переданной браузером. Для авторизации пользователя сервер должен проверять подпись `Telegram.WebApp.initData` и срок `auth_date`.

## Локальный запуск

Запустите любой статический HTTP-сервер из корня проекта, например:

```bash
python -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173`. В обычном браузере используются резервные кнопки; нативные Telegram-компоненты доступны внутри Mini App.
